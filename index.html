pale-lantern

個人用のメール整理ツールです。使うのは作った本人だけで、一般には提供していません。

何をするツールか

  • 本人の Gmail から、あらかじめ決めた差出人・件名に当てはまる通知メールだけを読み取ります
  • 読み取ったメールは、本人のパソコンの中で整理し、あとから検索できるようにします
  • ログインに確認コードが要る外部サイトのために、そのサイトのログイン受付アドレスへ空メールを1通送ります（返信で届く確認コードでログインします）

Google のデータの扱い

  • Gmail の読み取り（gmail.readonly）: 条件に当てはまる通知メールだけを検索して取り込みます
  • Gmail の送信（gmail.send）: 上に書いたログイン用の空メールを送るためだけに使います
  • データは本人のパソコンにだけ保存し、販売・広告・第三者への提供はしません

詳しくは プライバシーポリシー をご覧ください。

About (English)

pale-lantern is a personal email organizer used only by its developer; it is not offered to the public. It reads notification emails that match predefined senders and subjects from the developer's own Gmail account, organizes them on the developer's own computer for later search, and sends one blank email to an external site's sign-in address when that site requires a sign-in code (the code arrives as a reply). Google user data is stored only on the developer's own computers and is never sold, used for advertising, or shared with third parties. See the Privacy Policy.
