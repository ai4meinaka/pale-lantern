プライバシーポリシー

pale-lantern（以下「このツール」）が Google のデータをどう扱うかを説明します。

このツールについて

このツールは個人用のメール整理ツールです。一般には提供しておらず、使うのは作った本人だけです。

読み取る Google のデータ

  • Gmail のメッセージの読み取り（https://www.googleapis.com/auth/gmail.readonly）
    あらかじめ決めた差出人・件名に当てはまる通知メールと、外部サイトのログインで届く確認コードのメールだけを検索して読み取ります。 読み取るのは、件名・本文・差出人・日時・添付ファイル・メールのヘッダです。条件に当てはまらないメールは取り込みません。
  • Gmail の送信（https://www.googleapis.com/auth/gmail.send）
    ログインに確認コードが要る外部サイトのために、そのサイトのログイン受付アドレスへ空メールを1通送るためだけに使います（返信で届く確認コードでログインします）。ほかの宛先にメールを送ることはありません。

使い道

  • 本人に届いた通知を整理し、あとから検索したり、期限を確かめたり、本人の質問に答えたりするためだけに使います
  • 質問への答えを作るときは AI サービスを使います（下の「第三者への提供と、外部のサービスへの送信」）
  • 広告、販売、信用の評価には使いません。AI モデルの学習（訓練）にも使いません

保存と保護

  • 読み取ったデータは、本人のパソコン（ツールを動かすパソコンと、バックアップを置くパソコン）にだけ保存します。インターネット上のサーバーには置きません
  • Google との通信は暗号化（HTTPS）されています。ログインに使う認証情報も本人のパソコンの中にだけ保存し、公開しません

第三者への提供と、外部のサービスへの送信

  • 読み取ったデータを第三者に販売したり、共有したりしません
  • 例外は1つだけです。本人が質問したときに限り、答えを作るために、質問と、それに関係する記録の抜粋（最大8件・各数百字）を Google の AI サービス「Google Antigravity」に送ります
  • Google Antigravity は、やり取りをサービスや AI モデルの改善に使わない設定（データ収集をオフ）にしています
  • 送った内容の写しを Google Antigravity のツールが本人のパソコンに残しますが、このツールが答えのたびに消します（会話の題名の一覧だけは残ります）
  • これ以外の外部のサービスには送りません

Google API サービスのユーザーデータに関するポリシー

このツールが Google API から受け取った情報の利用と、ほかのアプリへの転送は、 Google API サービスのユーザーデータに関するポリシー（Limited Use の要件を含む）に従います。

保存期間と削除

  • データは、本人が使う間だけ保存します。本人はいつでもパソコン上のデータを消せます
  • このツールへのアクセス権は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます

Privacy Policy (English)

About. pale-lantern is a personal email organizer. It is not offered to the public; the developer is its only user.

Google data accessed.

  • gmail.readonly: the tool searches the developer's own Gmail only for notification emails that match predefined senders and subjects, and for sign-in code emails from an external site, and reads their subject, body, sender, date, attachments and headers. Other messages are not imported.
  • gmail.send: used only to send one blank email to an external site's sign-in address when that site requires a sign-in code (the code arrives as a reply). No other emails are sent.

Use. The data is used only to organize and search the notifications the developer receives, to check due dates, and to answer the developer's own questions (an AI service writes the answers; see Sharing). It is never used for advertising, sold, used for credit decisions, or used to train AI models.

Storage and security. Data is stored only on the developer's own computers (the one that runs the tool and the one that keeps its backup), never on internet servers. Communication with Google uses HTTPS, and credentials are kept only on those computers.

Sharing. The data is not sold or shared with third parties. The one exception: only when the developer asks a question, the question and excerpts of related records (up to 8, a few hundred characters each) are sent to Google's AI service "Google Antigravity" to write the answer. Google Antigravity is set not to use the interactions to improve its services or AI models (data collection turned off). The copies that Google Antigravity's tool leaves on the developer's computer are deleted by this tool after each answer (only a list of conversation titles remains). The data is not sent to any other external service.

Limited Use. pale-lantern's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion. Data is kept only while the developer uses it and can be deleted from the computers at any time. Access can be revoked at any time from Third-party apps & services in the Google Account.

Changes. Any change will be published on this page with an updated date.
